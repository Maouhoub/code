After each pruning iteration, rebuild the affected layers (attention and MLP) to remove the pruned heads/channels.

For each pruned attention layer:
Create a new attention module with reduced num_heads and copy only the unpruned weights.
For each pruned MLP:

How:

Write a utility function (e.g., rebuild_pruned_layers(model, mask_manager)) that:

Constructs new modules with reduced dimensions.
Copies over surviving weights/biases.
Replaces the old modules in the model.
